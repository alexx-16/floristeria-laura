# Floristeria Laura

¡Bienvenido al repositorio oficial de la web de **Floristería Laura**! Este sitio web está desarrollado en HTML5 y CSS3 para mostrar el catálogo de ramos, plantas y ofertas especiales de la tienda.

## Ver a web publicada
Puedes acceder a la versión en línea desplegada en GitHub Pages a través del siguiente enlace:
 **[Ver Floristería Laura en GitHub Pages](https://alexx-16.github.io/floristeria-laura/)**

## Tecnologías utilizadas
* **HTML5:** Estructura de la página web.
* **CSS3:** Estilos, colores y maquetación responsive.
* **GitHub Pages:** Despliegue y alojamiento gratuito de la web.

## Estructura del proyecto
* `index.html` - Página principal de la floristería.
* `css/` - Carpeta que contiene las hojas de estilo de la web.
* `img/` - Carpeta con las imágenes de los productos y flores.
